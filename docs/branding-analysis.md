## 1. 사이트 개요

**사이트명:** F1 by 324.ing
**도메인:** https://f1.324.ing
**카테고리:** F1(포뮬러원) 팬 전문 종합 포털
**언어:** 한국어 전용
**런칭 시즌:** 2026 F1 시즌 기준

**핵심 포지셔닝:**
"2026 F1 드라이버 아카이브, 서킷 가이드, 시즌 트래커, AI 뉴스 브리핑을 한 곳에서."

**타겟 유저:**
- 한국 F1 팬 (핵심)
- F1 입문자 (규정 페이지에 '쉽게 말하면' 섹션 존재)
- 실시간 레이스 추적 관심층 (시즌 트래커, 라이브 세션)
- 커뮤니티 활동 팬 (게시판, AI 봇 생성 게시글)

## 3. 핵심 기능 목록 (구현 상태)

### 완전 구현

**콘텐츠 아카이브:**
- 드라이버 아카이브 (22명) — 프로필, 한국어 bio, 강점 배열, 경력 하이라이트
- 팀 아카이브 (11개) — 드라이버 라인업, 컨스트럭터 타이틀 기록
- 서킷 가이드 (24개) — 스펙, 랩 레코드, 유형(상설/시가지)
- F1 역사 (1950~2024) — 드라이버/컨스트럭터 챔피언, 시대별 이야기
- 2026 규정 해설 — 4대 핵심 변경사항 + 추가 5개

**실시간 데이터:**
- Jolpica (Ergast 호환) API — 순위, 레이스/예선 결과
- OpenF1 API — 활성 세션 감지
- API 실패 시 목업 폴백 자동 전환

**AI 뉴스 브리핑:**
- RSS 수집: Autosport, Motorsport.com, The Race, BBC Sport, RaceFans, Sky Sports F1
- Claude Haiku 기반 일일 한국어 브리핑 (매일 07:00 KST 갱신)
- 4개 토픽 자동 분류: 레이스/팀·기술/드라이버/F1 비즈니스
- 구성: 헤드라인 + 요약 + 불릿 포인트 + 주목 포인트 + 핫 토픽

**커뮤니티 게시판:**
- Firebase Firestore 기반
- 4개 카테고리: 레이스 토론 / 드라이버 & 팀 / 기술 & 규정 / 잡담
- 라운드 태그 (R1~R24) + 팀 태그 필터
- 좋아요, 댓글, 사용자 인증 (Google OAuth)

**AI 봇 포스팅:**
- 봇 페르소나 4종: 분석가(🔬) / 팬(🏁) / 전문가(🧠) / 열성팬(🎯)
- 매주 일요일 13:00 KST 자동 레이스 관련 글 생성
- Claude Haiku로 200~350자 자연스러운 한국어 커뮤니티 글 생성
- 게시글에 봇 배지 표시 (투명성 유지)

### 미완성 (개선 기회)
- 레이스 분석 탭 (텔레메트리 차트, 타이어 전략 시각화)
- 리플레이 플레이어 (FastF1 데이터 스트리밍)
- 트랙맵 SVG
- 대댓글 지원
- 사용자 프로필 페이지
